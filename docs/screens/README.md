# Rider screens

Captured from Expo web at 390×844 (a phone viewport), signed in as the demo
rider against a local `gridgo-api`, in both Light and Dark. Downscaled to 1× JPEG
so the PR stays small; the originals were 2×.

`before-*` are the same build the captain reported as "not there": the four-tab
bar with an off-centre disc, the Active screen with its primary action below the
fold, and the offer card with the fee off the bottom of the screen.

These exist to make a visual PR reviewable. They are safe to delete once the
change has been looked at.
